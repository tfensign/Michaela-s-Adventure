# Michaela's Adventure

Michaela, Freya and Dragon hike 8 trails: side quests, puzzles and buried treasure.

- `android/` is the Android app (a full-screen offline wrapper around the game). Every push builds `MichaelasAdventure.apk`
  with GitHub Actions and attaches it to a new release on the **Releases** page.
- `web/` is the game as an installable web app (open `web/index.html` to play in a browser).

To install on Android, open the newest release on your phone, tap **MichaelasAdventure.apk**, and allow installing from
your browser when asked.
